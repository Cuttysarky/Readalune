# Changelog

All notable changes to Readalune are listed here. Versions follow [Semantic Versioning](https://semver.org).

## 1.0.0 - first release

**Reading**
- Paginated reading with "Page X of Y", percent read and time left, or continuous scroll.
- One or two pages side by side; slide, page-curl, fade or no page-turn animation.
- Six themes, seven font styles, and adjustable size, spacing, margins, justification and hyphenation, globally or for one book.
- Table of contents, full-text search, go to page or percent, and "Back to page N" after a jump.
- Read aloud with the system's voices, with a sleep timer.
- Comic (CBZ) reading with spreads, right-to-left mode and zoom; original-layout view for PDFs.

**Notes and library**
- Highlights in five colours, notes, bookmarks, quote images and a Word Journal; export as Markdown, JSON or CSV.
- Library with collections, tags, ratings, reading status, series, bulk editing and search inside every book.
- Folder import and watched folders, backup and restore, and reading statistics with a yearly goal.
- 1,000 classics from Project Gutenberg, which lists them as public domain in the United States. Copyright rules differ in other countries; see LEGAL.md.
- A cover drawn in code for every book that has no cover image, with an emblem that suits the book (a whale for *Moby Dick*, a windmill for *Don Quixote*). No cover images are stored.

**Files**
- Imports TXT, Markdown, HTML, EPUB, PDF and CBZ. DRM-protected files are refused, never unlocked.
- Opens books from the system: double-click an EPUB or CBZ, use *Open with Readalune*, or drop a file on the app icon.

**Privacy, safety and reliability**
- No accounts, tracking, ads or network connections; everything stays on the computer.
- Sandboxed interface, strict Content-Security-Policy, validated IPC and Electron security fuses.
- Recovers from a crashed or frozen window without losing the library, and keeps a small local error log.
- *Help > Check for Updates* opens the Releases page in the browser; the app never updates itself.
